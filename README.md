# My GitHub Website

A simple portfolio website based on the supplied design:

- Orange navigation bar
- Cyan background
- Welcome home section
- My Activity section
- My Project section
- Two-column cards on desktop
- One-column cards on mobile
- Internal vertical scrolling for activities/projects
- Smooth navigation between sections

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Replace the placeholder activity/project names and `href="#"` links with your real content.
